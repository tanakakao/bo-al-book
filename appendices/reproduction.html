実験の生成式とAPI対応

材料試験を生成する

第1・4〜9章の共通の合成関数は、温度を °C の数値 \(T\) で表すと、\(x=(T-140)/40\) に対して

\[ g(x)=70+12\sin(2\pi x)+4\cos(4\pi x)+5x \]

です。出力の単位は MPa です。教材の notebooks/experiment.py にある material_strength(x) がこの式を計算します。第1・6章は測定値を \(g(x)\) とし、第4・5章の observations() は \(x=(0.05,0.25,0.43,0.62,0.86,0.96)\) で \(g(x)\) に標準偏差2 MPaの独立な正規ノイズを加えます。乱数シードは2026です。fit_material_gp は既知の観測分散を train_Yvar で渡し、robotorchanの SingleTaskGP.fit() で学習します。本書の版で、この例が利用するBoTorchの既定構成は、定数平均、長さ尺度に事前分布を持つRBFカーネル、出力標準化です。手計算例などで別のカーネルを使うときは各章で指定します。

第8・9章の notebooks/classification_experiment.py では、別々の試験片の合格確率を \(\Phi((g(x)-74)/2)\) とします。これは \(g(x)\) に標準偏差2 MPaの正規ノイズを加え、74 MPa以上を合格にする手順に対応します。各候補の一様乱数が合格確率を下回ると合格ラベルを返します。分類器へは温度と二値ラベルを渡します。分類器はMatérn 5/2、長さ尺度の初期値0.18、固定誘導点9個、ProbitのBernoulli尤度を用います。Adamの学習率は0.03で、全データを1バッチとして第8章では60、第9章の主例では120エポック学習します。

robotorchanとBoTorchで同じ試験を組む

作業 本書のrobotorchan API BoTorch・GPyTorchでの構成
GP回帰を学習 SingleTaskGP の fit() GPと厳密周辺尤度を組み立て、fit_gpytorch_mll で学習
次の測定点を選ぶ optimize_acqf optimize_acqf に獲得関数、境界、候補数を渡す
合否のGPを学習 二値GP分類器の fit() 変分GP、Bernoulli尤度、変分下界を組み合わせる
測定と登録を反復 create_study、ask、tell 自分で試行履歴を保持し、学習・候補提案・測定・追記を繰り返す

候補を選ぶ optimize_acqf は両ライブラリにあります。以下の別名で読み込むと、呼び出し元を区別できます。第5・6章で使う LogExpectedImprovement などの獲得関数はBoTorchから読み込みます。

from robotorchan.optim import (
    optimize_acqf as optimize_with_robotorchan,
)
from botorch.optim import optimize_acqf as optimize_with_botorch
from robotorchan.models.classification import (
    BinarySingleTaskGPClassifier,
)
from gpytorch.likelihoods import BernoulliLikelihood
from gpytorch.mlls import ExactMarginalLogLikelihood, VariationalELBO

BoTorchでGP回帰を学習するときは、尤度とモデルから ExactMarginalLogLikelihood を作り、fit_gpytorch_mll に渡します。合否の分類をGPyTorchで組むときは、変分GPと BernoulliLikelihood を使い、VariationalELBO を最大化します。

試行を発行して評価結果を後から返す形は OptunaのStudy の ask／tell にもあります。第6・10章ではモデル、獲得関数、候補最適化の構成を指定するrobotorchanのStudyを使います。Optunaへ移す場合は、探索空間、試行を選ぶサンプラー、状態や永続化の扱いをそれぞれのAPIで確認します。

章末演習の解答・解説

第1章

  1. \(3+6=9\) 回です。候補を細かくすると、選択前に評価する獲得関数の値は増えます。追加の試験数は、候補集合の大きさと独立に6回と決められます。
  2. n_extra を3に変えると、各方法は初期3件と追加3件で終了します。図の横軸の最後が6、各手法の evaluation_count が6になっているか確認します。固定格子とBOでは最初の3追加点の順が同じ設定のままです。ランダムのシードを変えるには random_generator を作る行の manual_seed に別の整数を渡します。
  3. 最良観測値には測定誤差が含まれます。候補の温度と現行条件で反復測定し、平均とばらつきを比較すると、偶然高かった試験結果の影響を調べられます。最後の推薦で測定誤差を含む一回の成績と、平均として期待する品質をどちらも見ると、判断の理由を説明しやすくなります。

第2章

  1. 事後分散は \(1/(1/25+1/9)=225/34\) です。平均は \(70.735\) MPa、標準偏差は \(2.572\) MPaです。事前精度 \(1/25\) と、1件の観測の精度 \(1/9\) を足します。
  2. noise_sd を6にすると1件の精度は \(1/36\) となります。4件の事後平均は約71.838 MPa、標準偏差は約2.572 MPaです。標準偏差3 MPaの設定では同じ4件で約72.294 MPa、1.437 MPaです。精度が下がると事前平均により近くなります。 観測平均が同じなら、標準偏差6 MPaの測定4件の精度 \(4/6^2=1/9\) は、標準偏差3 MPaの測定1件の精度 \(1/3^2\) に等しく、同じ事前の下で事後平均と分散は一致します。
  3. \(c=\rho(4)(5)\) を条件付き正規分布の式に入れます。\(\rho=0\) なら平均75 MPa、分散25 MPa²で周辺分布と一致します。\(\rho=-0.7\) なら平均は71.5 MPa、分散は12.75 MPa²です。符号は平均の更新方向に関わり、分散を減らす項には \(c^2\) が入ります。

第3章

  1. 距離と長さ尺度がともに0.5です。RBFの式から共分散は \(\exp(-1/2)\approx0.607\) です。
  2. 事前サンプルを描くセルの最初のRBF設定で、描画タイトルと ell をともに0.40へ変えます。例えば \(r=0.20\) における相関は \(\exp(-1/2)\approx0.607\) から \(\exp(-1/8)\approx0.882\) に増えます。近隣で同じ向きに動きやすくなります。信号分散を固定しているので各点の分散は同じです。
  3. 上左の \(K_{XX}\) のうち、\(x=0\) と \(x=1\) それぞれの対角2成分にだけ0.1を足します。観測誤差は独立と仮定しているので、観測位置同士の非対角はそのままです。予測の対象を潜在強度とした場合、予測側ブロックにも観測誤差を加えません。

第4章

  1. 標準偏差は \(\sqrt{3^2+2^2}=\sqrt{13}\approx3.606\) MPa、約95%区間の半幅は \(1.96\sqrt{13}\approx7.07\) MPa です。
  2. Notebookの check_noise_variance を0.5に変更すると、GPと手計算の両方に同じ分散が入ります。\(A^{-1}\) を通じて観測の補正が弱まり、この小例では各点の平均が零に近づきます。事後分散は各点で増えます。\(\tau^2 I\) を大きくすると、正定値行列の逆の順序が逆転し、\(K_{*X}A^{-1}K_{X*}\) が半正定値順序で小さくなるためです。
  3. Notebookの matern_lengthscale だけを0.10と0.35に変え、たとえば \(x=0.73\) の周辺を読みます。この例では短い長さ尺度のモデルほど離れた点の影響が弱く、観測間で事前平均へ戻りやすくなります。目盛の揃ったグラフ上で平均と区間幅を判断し、長さ尺度変更が常にすべての位置の帯に同じ方向の効果を与えるとは結論しません。
  4. 標準正規乱数を共通にして倍率だけを6 MPaに変えれば、測定値の違いとモデルの仮定の違いを追いやすくなります。両方の実験で同じ入力位置・同じ事前仮定・同じ観測分散 \(36\,\mathrm{MPa}^2\) を使うと、潜在事後共分散は一致します。測定値を作り直した実験では \(\mathbf y\) が変わるため、事後平均への補正量が変わります。

第5章

  1. Aの \(z\) は2、Bの \(z\) は \(-0.25\)。PIは約0.9773と0.4013でAが上位です。EIは約1.0042 MPaと1.1454 MPaでBが上位です。UCBは \(81+2(0.5)=82\) MPa と \(79+2(4)=87\) MPa でBが上位です。Bは改善の頻度が低くても、起きたときの改善量が大きくなり得ます。
  2. \(\beta=0\) は平均を最大にする点です。係数を上げると平均が多少低くても標準偏差の大きい点が有力になります。候補の \(x\) 値を比べるだけでなく、候補ごとの \(\mu,\sigma\) を出力し、UCBの2項のうちどちらが効いたかを調べます。
  3. \(b=78\) MPa では、PIはAがほぼ1、Bが約0.599で、EIはAが3.000 MPa、Bが2.145 MPaです。両方でAが上位です。\(b=82\) MPa では、PIはAが約0.023、Bが約0.227で、EIはAが0.004 MPa、Bが0.525 MPaです。両方でBが上位です。PIの順位は \(z_A=z_B\) となる \(b=81+2/7\) MPa を境に変わります。極端な閾値で評価値が桁落ちして同点に見える場合は、標準化した \(z\) や対数領域のスコアも確認します。
  4. ある観測に偶然大きい正の誤差が乗ると、観測最大値が真の最高強度より高くなり得ます。その観測値を固定基準にすると、別の有望条件でも改善確率や期待改善がほぼ消えることがあります。候補と既観測点の潜在値について、現在の事後分布で不確かさを扱う noisy EI 系がこれに対応する一例です。

第6章

  1. 初期4回と追加4回で装置測定は8回です。モデル学習や獲得関数の内部評価は実験予算を消費しません。推薦温度を実機で1回確認すれば合計9回になります。
  2. fail_number = 0 とします。4試行の状態は FAIL, COMPLETE, COMPLETE, COMPLETE です。目的値を得た3件が登録されます。
  3. 例えば成功した試行を3回追加した後の最良観測値の改善が0.2 MPa未満なら停止候補とし、一定の測定予算内で確認します。失敗試行は累計の試行数に含め、測定値・改善履歴には加えません。測定ノイズが0.2 MPa程度以上なら観測の増分が誤差で変動するので、反復測定や事後予測も参照します。

第7章

  1. 各seedの8点の学習データ、256点の検証データ、信号モデルと出力標準化、観測分散を固定します。入力変換は \(x_T=(T-140)/40\) と \(x_r=r/0.01\) です。ベイズ最適化まで行う場合も、モデルが内部で変換する設定なら候補探索の範囲は外部の物理座標で指定します。
  2. cases のノイズあり2行にある 2.0 を 4.0 へ変えます。同じseedの誤差を2倍にするため、各方式の違いを追いやすくなります。best_observed_mpa は実測の最大、recommendation_gap_mpa はシミュレータの真値で測った推薦点と最大との差です。両方をseedごとに比較し、観測最大値が上がった場合も、推薦点の差が減ったかを確認します。
  3. 2点をまとめて提案して計測する場面では評価回数は2です。開始から両方終わるまでの経過時間には、準備や評価待ちも含めます。片方が先に終わり、すぐに次を提案する運用では、完了点と保留点を区別します。両方が終わってから次の一組を提案する運用と比べるなら、同じ実測数に達するまでの時間と同じ終了時刻までの実測数をそれぞれ記録します。

第8章

  1. どちらも平均確率は0.5なので、予測エントロピーは \(\log 2\approx0.693\) natです。常に0.5ならBALDは0です。0.2と0.8が等確率なら、対称性で条件付きエントロピーは \(h(0.2)\approx0.500\) nat、差は約0.193 natです。
  2. 比較用の test_x を作った直後に test_x = test_x[test_x[:, 0] >= 0.625] と絞り込み、それから truth と学習曲線を作り直します。物理温度165 °Cは正規化座標0.625です。選択に使うスコアはそのままなので、各シードの候補順と取得ラベルは同じです。評価する温度の重みが変わり、同じ予測でも、損失の平均が変わります。
  3. \(c(z,x)=0\) なら、その一回の測定で \(z\) の分散は減りません。候補の \(s^2(x)\) と測定ノイズが同じなら、\(|c(z,x)|\) が大きい方が \(z\) での分散を大きく減らします。対象を有限個の \(z_j\) と非負の重み \(w_j\)（\(\sum_j w_j=1\)）で表すなら、各候補で \(\sum_j w_jc(z_j,x)^2/[s^2(x)+\sigma_n^2]\) を計算して最大のものを選びます。カーネル等を固定する前提です。

第9章

  1. \(\Phi(1)\)、\(\Phi(1/2)\)、\(\Phi(1/3)\) なので、およそ0.841、0.691、0.631です。\(m_x=0\) のとき平均合格確率はどの分散でも0.5です。潜在標準偏差 \(s_x\) が増えると \(\Phi(-z_{.975}s_x)\) は小さく、\(\Phi(z_{.975}s_x)\) は大きくなり、確率の信用区間は広がります。
  2. Notebookの decision_threshold を0.8にすると、予測確率0.5以上0.8未満の判定が1から0になります。この範囲の正解ラベルによって誤分類率が変わります。Brier損失と対数損失は判定ラベルを使わないため変わりません。
  3. 例えば第9章の学習呼び出しの epochs=120 を一律40にして、同じ初期データ、学習seed、評価ラベルで比較します。帯の幅は一方向に動くとは限りません。新しいBALD最大点と、試験前・試験後の値をそれぞれ記録します。評価ラベルを使ってエポック数を選ぶと、同じ評価ラベルでの最終報告に調整の影響が入ります。
  4. 第1項は \(\mathbb E[P_x]-\mathbb E[P_x^2]\)、第2項は \(\mathbb E[P_x^2]-\mathbb E[P_x]^2\) です。二次の期待値が相殺され、\(\bar p_x-\bar p_x^2\) が残ります。

第10章

  1. その条件で0 MPaという測定を得たことになります。タイムアウトなら強度を欠測とし、TrialState.FAIL として理由を記録します。この教材のStudyで学習するのは完了行です。
  2. 下限15分の宣言と過去ログの10分・13分が矛盾するため、登録前の範囲検査で止まります。教材で新しいStudyに取込むには、古い表を保存したうえで、その2行を範囲外として除外します。範囲外を含む過去データが新範囲の予測に役立つかは別の検証です。含める場合は、モデルの学習に使う領域と候補を出す領域を実装上も分けます。
  3. 製造可・不可と判定理由、分かれば限界に対する測定余裕を、強度とは別に記録します。候補時点で分かる装置制約は適用できる入力を先に制限し、試験しないと分からない製造適合性は未知の出力として扱えます。強度を取得できなかった行へ架空の強度を入れる必要はありません。

第11章

  1. DはCより強く、エネルギー消費も小さいため、Cの矩形はDの矩形に含まれます。参照強度を75から76へ上げると、高さ \(14-7=7\) kWh、幅1 MPaの部分が除かれ、面積は30 MPa·kWhになります。
  2. 状況ごとの最良行動は0と1で、平均効用は \(0.75(5)+0.25(6)=5.25\) です。操作0に固定すると4.00、操作1に固定すると3.00です。状況を知る前の固定操作としては0を選びます。
  3. 操作は温度・保持時間、状況は事前に観測したロット、観測は実際に得た強度です。装置の既知制約で実行可能集合を決めます。過去ログではロットごとの設定の重なり、設定を選んだ理由、装置や時期に伴う変化を調べます。比較可能なログが不足する場合は、許可された共通条件で追加測定します。

第12章

  1. 確認は計4回なので、適応的な追加候補の枠は \(20-6-4=10\) 回です。失敗1回も枠を使うので、追加の成功観測は最大9件です。
  2. 閾値は \(2/(2+1)=2/3\) です。0.66は閾値未満なので不合格、0.91は閾値以上なので合格です。表示を2桁に丸めた0.67から判定するより、計算で得た閾値をそのまま使います。
  3. ロット間で試料調製や装置条件を記録し、候補選択で見るロットと評価へ残すロットを決めます。新しいロットへの汎化を評価したい場合は、ロット全体を学習から外して試します。必要な評価サンプル数、費用、希少な不合格をどう数えるかも先に決めます。

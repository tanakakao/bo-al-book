# 書籍紹介文案

## 紹介ページ用

**Pythonで学ぶベイズ最適化と能動学習 第1巻 基礎理論と実践**

材料の強度を高めたいとき、限られた回数で次にどの条件を測るべきでしょうか。合否しか返らない試験では、どの観測が予測の改善につながるのでしょうか。本書は、こうした問いを出発点に、確率・統計とガウス過程から、ベイズ最適化、能動学習、二値GP分類までを学ぶ技術書です。

同じ合成材料試験を題材に、予測の不確かさをどう読むか、改善確率と期待改善量でなぜ選ぶ点が変わるか、測定結果を登録した後に候補をどう更新するかを、数式とPythonで確かめます。後半ではCSVの読み込みから候補提案、失敗の記録、独立した確認測定までを扱い、実験計画と評価指標を結び付けます。

Pythonの関数や配列を使ったことのある学生、技術者、研究者が対象です。ガウス過程とベイズ最適化を初めて学ぶ読者も、第1章の候補提案から読み始められます。PyTorch、GPyTorch、BoTorch、robotorchanを使う実行済みNotebook全12本、合成データ、章末演習と解答を収録しています。
